Build a small Lex library package named "semver": validate and compare semantic versions and test them against ranges. It is a pure library: no network, no database, no files, no environment. Use only the Lex standard library (std.str, std.list, std.int and the like); do not depend on any other package. Every function is pure (no effect annotation) and every function has examples.

A version is "MAJOR.MINOR.PATCH" with an optional "-PRERELEASE" and an optional "+BUILD". MAJOR, MINOR and PATCH are non-negative integers written in decimal with no leading zeros (the single digit "0" is fine) and at most 9 digits each. PRERELEASE is one or more dot-separated identifiers; an identifier is non-empty and uses only letters, digits and "-"; an all-digit identifier must not have a leading zero. BUILD is one or more dot-separated non-empty identifiers of letters, digits and "-". There is no leading "v" and no surrounding whitespace: "v1.2.3", " 1.2.3", "1.2", "1.2.3.4", "1.2.3-" and "1.2.3+" are all invalid.

The package exposes exactly three functions, all taking and returning only plain values:

- semver_valid(s :: Str) -> Bool : whether s is a valid version.
- semver_compare(a :: Str, b :: Str) -> Result[Int, Str] : Err(message) if either is invalid, otherwise Ok(-1), Ok(0) or Ok(1) by semantic-versioning precedence. Compare MAJOR, MINOR, PATCH numerically. A version with a PRERELEASE is lower than the same version without one. Two PRERELEASE lists compare identifier by identifier from the left: all-digit identifiers compare as numbers, other identifiers compare as ASCII text, an all-digit identifier is lower than a non-digit one, and when all shared identifiers are equal the list with fewer identifiers is lower. BUILD is ignored entirely: "1.0.0+a" and "1.0.0+b" compare equal.
- semver_satisfies(version :: Str, range :: Str) -> Result[Bool, Str] : Err(message) if the version or the range is invalid, otherwise whether the version satisfies the range. A range is one or more comparators separated by exactly one space; the version must satisfy all of them. A comparator is a version with an optional operator in front: none or "=" (equal, by precedence), ">", ">=", "<", "<=", "^" or "~". "~X.Y.Z" means >=X.Y.Z and <X.(Y+1).0. "^X.Y.Z" means >=X.Y.Z and below the next change of the left-most non-zero number: if X is greater than 0 it is <(X+1).0.0; otherwise if Y is greater than 0 it is <0.(Y+1).0; otherwise it is <0.0.(Z+1). A comparator's version may carry a PRERELEASE (it takes part in the lower bound by normal precedence). There is no special rule for prerelease versions: they are compared by precedence like any other. An empty range, a range with leading, trailing or doubled spaces, an unknown operator, a space between operator and version, or a partial version like "^1.2" is invalid.

Worked examples (the answers are exact):

- semver_valid("1.2.3-alpha.1+build.5") is true; semver_valid("01.2.3") is false.
- semver_compare("1.0.0-alpha", "1.0.0") is Ok(-1); semver_compare("1.0.0-beta.2", "1.0.0-beta.11") is Ok(-1) (2 < 11 as numbers); semver_compare("1.0.0-1", "1.0.0-a") is Ok(-1); semver_compare("1.0.0-alpha", "1.0.0-alpha.1") is Ok(-1); semver_compare("1.0.0+a", "1.0.0+b") is Ok(0); semver_compare("1.2", "1.2.3") is an Err.
- semver_satisfies("1.9.9", "^1.2.3") is Ok(true); semver_satisfies("2.0.0", "^1.2.3") is Ok(false); semver_satisfies("0.2.9", "^0.2.3") is Ok(true); semver_satisfies("0.0.4", "^0.0.3") is Ok(false); semver_satisfies("1.2.9", "~1.2.3") is Ok(true); semver_satisfies("1.3.0", "~1.2.3") is Ok(false); semver_satisfies("1.4.99", ">=1.0.0 <2.0.0") is Ok(true); semver_satisfies("1.2.3", ">= 1.0.0") is an Err.

Properties that must hold and be checked: semver_compare(a, b) is Ok(x) exactly when semver_compare(b, a) is Ok(-x); semver_compare(a, a) is Ok(0) for every valid a; semver_compare is transitive on valid versions; no function ever panics on any string.
